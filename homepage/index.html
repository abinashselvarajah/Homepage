Synthetic vs. Real

Can virtual images replace real ones when training industrial recognition systems? My project investigates how suitable synthetic data is.

I started from a real image dataset of 3D-modelled Makeblock parts and recreated it in Unity. With the Perception tool, I generated synthetic images using domain randomizers for colour, rotation, texture, background and sun angle, which adds the variety a purely virtual dataset lacks.

On this data I trained a CNN for image classification in Keras and an SSD MobileNet V2 model for object detection with TensorFlow. I first compared the randomized parameters one by one, then trained networks on different shares of real and synthetic images and evaluated them with accuracy and detection metrics.

The result: synthetic data is a good way to extend a real dataset, but only if the randomization is chosen with care.

Robotics

AVAI 2023 · TurtleBot Racetrack

A TurtleBot3 had to drive a racetrack marked by coloured cones on its own. In ROS 2, a camera node feeds a YOLOv5 model that detects the cones, and LiDAR data is fused with the detections to place them in space. Cartographer SLAM and an occupancy map keep track of the cones, and a movement controller steers towards the next target point between the blue and yellow cones.

  • ROS 2

  • OpenCV

AVAI 2025 · Racecar

The same challenge, now on a racecar with Ackermann steering. A RealSense camera and a YOLOv11 Nano model, trained on real and synthetic cone images, detect the cones. We fuse these detections with LiDAR data, cluster them with DBSCAN into an occupancy map and let a controller compute the path through the track.

  • Python
  • ROS 2
  • YOLOv11
  • OpenCV

Human-Centered Robotics · YuMi

An assistance system for a worker with cerebral palsy in a sheltered workshop, who presses small rubber and metal parts together. The dual-arm ABB YuMi supports this task and is programmed in Python, with robot targets taught by hand and stored as JSON. The worker talks to it: the hot word “Hey YuMi” is detected with Picovoice Porcupine, speech is processed with Google Speech-to-Text, and ChatGPT provides small talk. A safety concept completes the system.

  • Python
  • ABB YuMi
  • RAPID
  • Porcupine
  • ChatGPT
